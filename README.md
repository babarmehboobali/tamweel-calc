# Tamweel Calc (تمويل كالك)

On-device GCC loan eligibility, EMI, amortization, comparison and early-payoff planner.

## Setup

```bash
flutter pub get
bash tool/fetch_fonts.sh
bash tool/render_icons.sh
dart run flutter_launcher_icons
dart run flutter_native_splash:create
flutter run
```

See `docs/` for AdMob, rates, privacy, regulations and release.
